# Dota2 数据查询助手

在群里养一个懂 Dota2 的机器人：**绑定账号就能查战绩，想看门道让它做 AI 复盘，被关注的队友一打完比赛自动播报。**

数据来自 STRATZ / OpenDota 公共接口，**不需要 Steam API Key**，装上就能用。报告全部说中文（英雄、道具、技能都是国服官方名）。

**目录**：[它能帮你做什么](#它能帮你做什么) ｜ [安装](#安装) ｜ [五分钟上手](#五分钟上手) ｜ [指令速查](#指令速查) ｜ [直接说人话](#不用记指令直接说人话) ｜ [自动播报](#比赛结束自动播报) ｜ [常见问题](#常见问题) ｜ [常用配置](#常用配置) ｜ [数据说明](#数据说明)

## 它能帮你做什么

| 你想做的事 | 怎么说 |
|---|---|
| 绑定自己的账号 | `/d2 绑定 天鸽` |
| 看最近战绩 | `/d2 战绩` |
| 让 AI 点评最近的发挥 | `/d2 分析` |
| 深度复盘某一局 | `/d2 单场 8989601141` |
| 查当前版本哪些英雄最强 | `/d2 轮椅` |
| 从版本强势英雄里挑适合我的 | `/d2 轮椅 我` |
| 比赛一结束自动收到播报 | `/d2 监听` |
| 懒人模式：不记指令，直接说人话 | `dota2助手 昨天谁打得好` |

特色：

- 🎯 **AI 复盘**：不是甩一堆数字，而是给出走势、质量评估、关键转折与可执行的改进建议。
- 📣 **赛后播报**：被监听的人打完一局，群里自动收到一段简短点评（不 `@` 任何人，不刷屏）。
- 🦽 **版本答案**：一条指令看清当前版本谁最强，还能结合你的英雄池告诉你「你该练哪个」。
- 🗣️ **听得懂人话**：`dota2助手 这局 8989601141 复盘一下`、`对比一下监听的几个人谁最菜` 都能接。
- 🕐 **认识时间**：「昨天谁打得好」「上周谁胜率最高」会真的按那个时间段统计，而不是拿最近几场凑数。
- 🎮 **认得出开黑**：「昨天群里开黑谁最牛逼」会先找出你们**同场**的局，再在里面比高下。
- 🔁 **双数据源**：主源抖动时自动切换后备，查询不会因为一家接口抽风就失败。
- 🆓 **开箱即用**：不填任何 Key 也能用全部功能（填了会更稳、更快）。

## 安装

1. 把 `astrbot_plugin_dota2` 整个目录放进 AstrBot 的 `data/plugins/` 下；
2. 在 AstrBot WebUI 的「插件管理」里重载插件（让它出现在插件列表）；
3. 打开插件配置，按需填写——**全部留空也能正常使用**，常见需要填的只有两项：
   - 服务器在国内、访问接口慢 → 填 `http_proxy`（如 `http://127.0.0.1:7890`）；
   - 想让**报告单独走自己的模型** → 填 `llm_api_key` / `llm_base_url` / `llm_model`。

> **模型怎么分工的**：群里唠嗑、说人话查战绩（含模型自己调工具）走的是 **AstrBot 全局配置的默认模型**；只有**比赛分析**（`/d2 分析`、`/d2 单场`、监听短评、定时播报）才优先走你在这里填的**插件专用 Key**。专用 Key 按量计费、专为长文准备，拿它接闲聊等于把群里的日常唠嗑记到分析账上 —— 所以两者是分开的。默认模型拿不到、或它调不动工具时，闲聊会自动回退专用 Key，功能不会因此缺一块。

依赖只有 `httpx`，AstrBot 本体已内置，**无需额外安装**。

## 指令速查

所有指令都以 `/d2` 开头（`/dota2`、`/刀塔` 同样有效）。

### 账号

| 指令 | 作用 |
|---|---|
| `/d2 绑定 <昵称 \| 32 位账号 ID \| 64 位 SteamID>` | 绑定账号 |
| `/d2 解绑` | 解除当前会话的绑定（同时清掉该账号的监听） |
| `/d2 我的` | 查看自己绑了谁 |
| `/d2 绑定列表` | 查看本会话所有绑定 |

### 查询

| 指令 | 作用 |
|---|---|
| `/d2 战绩 [场次] [目标]` | 最近战绩，默认 20 场 |
| `/d2 分析 [场次] [目标]` | AI 分析近期表现与打法风格 |
| `/d2 单场 <比赛ID> [焦点玩家]` | AI 深度复盘单场比赛 |
| `/d2 资料 [目标]` | 玩家资料、段位、生涯胜率、当前版本常用英雄 |
| `/d2 英雄 [目标]` | 英雄池：**只看当前版本**，并包含加速模式 |
| `/d2 轮椅 [位置] [目标]` | 当前版本强势英雄榜；带目标时还会给出适合他的推荐 |

`目标` 可以填昵称、32 位账号 ID 或 64 位 SteamID；不填就用你在本会话绑定的账号。

**英雄池是按版本算的**：只统计当前补丁的场次。当前版本样本太少（默认门槛 30 场，
版本刚更新或最近打得少时会遇到）会自动并入更早的版本，并在抬头写明实际覆盖了
哪些版本。**加速模式也计入** —— 数据源默认会把加速局整套丢掉，而群里多数人
恰恰主要在打加速，不计入的话英雄池会缩到只剩零头；抬头会标出其中加速占多少场，
方便你判断这个胜率的含金量。

### 复盘与解析

| 指令 | 作用 |
|---|---|
| `/d2 单场 8989601141` | 未解析的局会**自动催解析并等待**，最多 10 分钟 |
| `/d2 单场 8989601141 skip` | 不等，立刻用现有数据出报告 |
| `/d2 催解析 8989601141` | 只排队催解析，不等结果 |

等满 10 分钟还没解析好？**不会空手而归**——自动改用现有数据出一份报告，并在开头标注数据完整度；等它解析好了再发一次同样指令，就能拿到完整版。

### 监听

| 指令 | 作用 |
|---|---|
| `/d2 监听 [目标]` | 开始监听，比赛结束后推送到本会话 |
| `/d2 取消监听 <目标 \| 全部>` | 取消（只能取消自己添加的） |
| `/d2 监听列表` | 查看本会话的监听 |

### 定时任务

不记指令也行，直接说人话。

| 指令 | 作用 |
|---|---|
| `/d2 定时` | 查看本会话的定时任务 |
| `/d2 定时 每天早上七点，通报群里战绩情况` | 直接描述你要的任务（先说清楚，回「确认」才建） |
| `/d2 定时 每监听到十盘战绩就生成一份这十盘的总结` | 按场次触发，不用等固定时间 |
| `/d2 定时 删 2` / `停 2` / `开 2` / `现在 2` | 删除 / 停用 / 启用 / 立刻跑一次 |
| `/d2 定时 改 2 早上八点` | 改执行时间（只给钟点就沿用原来的周期） |
| `/d2 定时 删 全部` | 清空本会话的全部定时任务（按时间 + 按场次） |

说人话管理已有任务（效果完全一样，不用记编号也行）：

```
dota2助手，取消所有定时任务          ← 本会话全部清掉
dota2助手 把定时任务都删了
dota2助手，看一下我建了哪些定时任务
dota2助手 把这个定时任务的执行时间改到早上八点
```

> 「改时间」只给钟点时会**沿用原来的周期**：把「每周五 23:00」改成「早上七点」，
> 得到的是每周五 07:00，不会变成每天都发。想连周期一起改就说全
> （「改成每天早上七点」）。

## 查版本强势英雄（轮椅）

想知道「这个版本练什么」，一条指令就够：

```
/d2 轮椅                ← 当前版本胜率最高的英雄榜
/d2 轮椅 辅助           ← 只看辅助位
/d2 轮椅 我             ← 榜单 + 从里面挑出适合你的
/d2 轮椅 核心 天鸽       ← 位置 + 目标一起给
```

位置可填 `核心` / `中单` / `三号位` / `辅助`（`大哥`、`1号位`~`5号位`、`酱油` 这些叫法也认）。

榜单分三段，各自回答不同问题：

| 段落 | 回答的问题 |
|---|---|
| **胜率最高** | 谁最能赢？（按胜率排，附样本量与近 3 天走势） |
| **热门里最横的** | 大家都爱玩的那几个里，谁最能赢？（避免推荐冷门偏方） |
| **悠着点** | 哪些当前版本别碰？（胜率垫底的） |

每个英雄都会标注**官方定位**（核心 / 辅助 / 三号位）、**主属性**、**样本量**，以及**近 3 天走势**（样本太少就不给结论，直接留白，不硬编趋势）。

带上目标（昵称或 `我`）之后，插件会：

1. 拉出他的**英雄池**（哪些英雄玩得多、胜率如何）和**近期逐场表现**（KDA / GPM / 分路分布）；
2. 把版本榜单和他的数据一起交给 AI，让它从**榜单内**挑出**他现在就能上分**的英雄，并按「已经在玩且版本强」「会玩但最近没动」「没玩过但定位相近」分类给建议；
3. AI 不通道（没配模型 / 接口挂了）时**自动降级**为纯数据交叉的规则版推荐，照样只在版本榜单内挑。

推荐**只会从榜单里挑人**，不会推荐榜单外的英雄、也不会编造数字；他某个英雄确实没数据时会写「无数据」，不拿 0 冒充。

> 关于口径：胜率榜的统计窗口是**最近 7 天**（不是严格按补丁切分）。如果当前补丁发布还不到 7 天，榜单里会混有上个版本的样本，此时报告开头会**明确提示**，不假装是纯新版本数据。

## 不用记指令：直接说人话

**默认需要在消息里带上唤醒词 `dota2助手`**（可在配置里改词或关掉）。带上它，就不用再 `@` 机器人了。没有唤醒词的消息，插件**完全不介入**，正常交给机器人自己回复。

```
dota2助手 帮我看看我的战绩              → 战绩查询
dota2助手 分析一下天鸽最近的发挥          → AI 近期分析
dota2助手 这局 8993438099 复盘一下       → 单场复盘
dota2助手 催一下 8993438099 的解析       → 催解析
dota2助手 天鸽的英雄池                   → 英雄池
dota2助手 把天鸽加入监听                 → 添加监听
dota2助手 监听列表                       → 查看监听
dota2助手 对比一下目前监听的几个人谁最菜    → 读监听名单 + 各人近期战绩，给你排序和依据
dota2助手 昨天谁打得好                   → 只统计「昨天」，窗口外的场次不计入
dota2助手 昨天群里开黑谁最牛逼             → 先找出你们同场的局，再比高下
dota2助手 我想转辅助，该怎么练             → 结合你的英雄池与近期表现给建议
dota2助手 这版本哪个英雄是轮椅            → 版本强势英雄榜
dota2助手 现在辅助胜率最高的是谁           → 版本强势英雄榜（只看辅助位）
dota2助手 我该练什么上分英雄              → 从版本强势英雄里挑适合你的
dota2助手 天鸽的轮椅有哪些                → 榜单 + 从里面挑适合天鸽的
dota2助手 钢板这版本玩什么上分英雄          → 同上（名字不用加「的」也认）
dota2助手 钢板最近打得怎么样，顺便推荐几个轮椅 → 两件事一起答：先看战绩，再从榜单里挑
dota2助手 昨天群里谁输得最惨？给他找两个轮椅 → 先算出谁最惨，再照他的英雄池挑
dota2助手 这版本什么英雄最强，我该练哪个     → 榜单 + 结合你的英雄池挑
```

几条规则：

- **改数据的操作先确认**：`绑定` / `解绑` / `添加监听` 会先回一句确认，你回「确认」才执行，「取消」就作废（可以直接回「确认」，不用再带唤醒词）。
- **群聊默认还要 `@` 机器人**：防止别人随口一句话就触发查询白耗配额，可在配置里关掉。
- **判意图靠 AI，关键词只管唤醒**：所以「详细分析这一盘」这种说法不会被误判成「分析最近 20 场」。
- **说话就行，剩下的交给模型**：命中唤醒词后，整条消息连同本会话的监听名单、绑定关系、各人近期战绩与**时间坐标**一起给模型，由它决定是直接回答、还是调用工具去查 / 去改。比如「昨天谁打得好」会被翻译成「昨天那一整天里各人的表现」，答得有依据，而不是编人名。想回到老路（关键词 + 意图分类）可以关掉 `nlu_chat_fallback`。
- **问「轮椅」时说谁的名字都认**：「天鸽的轮椅」「钢板的版本强势英雄」都能接 —— 本会话里绑定过或正在监听的名字会**先做精确匹配**（这些名字是当初真查出来的），没对上才按句子结构去抽。只问榜单、没提人时不会多拉个人数据。
- **一句话要好几样东西时，模型会自己连着办**：「钢板最近打得怎么样？顺便给他推荐几个轮椅英雄」这种一次要两个功能的说法，插件不会只挑一个答 —— 插件的**全部能力**都做成了工具（查战绩 / 查英雄池 / 查玩家资料 / 查版本强势榜 / 结合英雄池挑英雄 / 列本会话玩家 / 列定时任务 / 单场复盘 / 催解析 / 绑定 / 监听 / 定时任务增删改停），模型**按需调用**（一句话里能连调好几个），办完再一起回答。这一步走的是 **AstrBot 全局配置的默认模型**（4.x 的模型提供商支持函数调用），**不需要**插件专用 Key；默认模型拿不到、或它调不动工具时，会自动回退专用 Key，两条都没有才退回「关键词 + 意图分类」，功能不会缺。**会改数据的操作要你点头**：模型提出后插件会回一句确认请求，你回「确认」才执行；说「把定时任务都删了」这类**整批**操作时，模型填「全部」也会被正确转成「删掉本会话全部任务」，不会只删一条；**单场复盘 / 催解析**只发起后台任务，正文稍后自动发到本会话，不会卡住对话。
- **想要固定排版就用指令**：自然语言这条现在由模型组织语言（更灵活，但不像指令那样每次长得一模一样）。`/d2 战绩`、`/d2 分析`、`/d2 单场` 这些指令**一点没变**，需要稳定可复现的结果时继续用它们。
- **「先问是谁、再为他做事」也算两件事**：「昨天群里谁输得最惨？**给他**找两个轮椅让他翻身」会先算出昨天谁最惨，再照那个人的英雄池挑英雄。这类说法**不管 AI 判成什么都会被拦下来**交给兜底逐项查 —— 判定不依赖模型是否听话，所以不会再出现「只答了后半句、前半句悄悄消失」。

### 「这一盘」指的是哪一盘

说「这一盘」「刚才那把」「上一局」时，插件按这个顺序找：本会话刚提到过的比赛 → 本会话刚推送过的那一场 → 你在本会话绑定账号的最近一场。都对不上就反问你，不瞎猜。

### 「昨天」是哪一天

「昨天 / 今天 / 前天 / 上周 / 最近 3 天 / 9月14日」都能识别，而**一天的分界点是凌晨 4 点**，不是 0 点：

```
凌晨 02:40 打完的一局  →  算「昨天」
凌晨 04:00 之后打的    →  才算「今天」
```

因为玩 Dota 的人普遍熬夜——凌晨两点还在连排时问「昨天谁打得好」，你想看的必然是**昨晚那一拨**（含刚打完的凌晨局）。按 0 点切的话，你会得到「昨天没人打」这种恰好把昨晚 21~24 点整段排除掉的答案。

识别到时间词后，所有统计**只算这段时间内的场次**：胜率、KDA、GPM、死亡数全部收窄。某人这段时间一场没打，就如实说「他这段时间没打」，不会拿别的时间的数据凑数；取数范围也会自动放宽（10 场 → 至少 30 场），避免因为手上没有那段数据而误报「他没打」。

> 顺带一提，纯闲聊不会被时间词带跑：「今天天气怎么样」不会去拉任何接口。

### 「我们是不是一起打的」

判定开黑靠**同场**，不靠「几人排」：把各人战绩按比赛 ID 归并，同一场比赛里出现两位以上本会话成员，就是你们开黑的确凿证据，并会告诉你**是同队还是对位**。同队看谁贡献大，对位看谁赢了那一局——这也是唯一能直接横向比高下的场景。

数据源给的「几人排」字段只说人数、不说跟谁，而且经常缺，所以**缺字段一律按「未知」处理，绝不会当成单排**。

## 比赛结束自动播报

加一次监听，之后他打完比赛，群里就会收到这样一条：

```
🏁 比赛回顾 · 8995536921
2026-09-14 21:03（3 分钟前） · 时长 23:56 · All Pick
天辉 37 : 11 夜魇 · 天辉获胜
👤 焦点玩家：钢板 · Luna · 2/12/5 ❌负

这局钢板拿了个 Luna 被打成 2/12/5，23 分钟就结束了比赛，输得比较干脆。
对照他最近 10 场 40% 胜率、场均 KDA 2.8 的水平，这一局死亡数直接翻了三倍，
明显不在状态。（想要完整复盘用 /d2 单场 8995536921）
```

你需要知道的几件事：

- **只播报，不刷屏**：一篇短评 2~4 句，不 `@` 任何人。一局只发一条——就算这局有好几个人被你监听，也是在一段话里逐一点到。
- **很快**：只用胜负与 KDA，不依赖录像解析，比赛被收录后一两分钟就能发出。
- **不会漏**：推送失败会自动重试；重启后也会重新发现并补推（记录只有在**送出去**或**放弃**之后才会前进）。如果机器人掉线太久（同一场连续 10 次发不出去），会放弃这一条并继续往后走，不会一直空转卡住后面的比赛。
- **数量上限**：单个会话最多 5 个监听（`watch_max_per_session`）。
- **被踢出群 / 被拉黑会自动取消**该会话的监听，不再做无用功。
- 想要深度复盘（走势、团战、出装）还是用 `/d2 单场 <比赛ID>`。

> ⚠️ **QQ 官方机器人要在每个群单独开通主动发言权限**，否则推送会失败（平台报 `40034105 主动消息失败, 无权限`）。
> 开通方式：手机 QQ → 进该群 → 群设置 → 机器人 → 选中本机器人 → 打开「机器人主动在群聊内发言」。
> 这个开关**只有群主**看得到，且 QQ 客户端需 ≥ 9.2.90；私聊权限是独立的，私聊能发不代表群里能发。

## 定时播报与阶段总结

不想每次都自己敲指令？直接跟它说一句「以后每天做这件事」就行：

```
dota2助手 每天早上七点，通报群里战绩情况
dota2助手 每晚十点总结一下大家今天的表现
dota2助手 每周五晚上十一点推一下轮椅
dota2助手 明天早上八点通报一下战绩          ← 只做一次
dota2助手 每监听到十盘战绩就生成一份这十盘的总结   ← 按场次，不是按时间
```

它不会立刻就建：先把「什么时候、做什么、发到哪」列出来给你核对，你回一句
**「确认」**才真正建好——毕竟这玩意儿建错了会天天在群里发东西。

建好之后：

- **按时间的任务会出现在 AstrBot 的「未来任务」页面里**，可以在那儿改时间、停用、删除；
  在群里用 `/d2 定时` 也能看、能停、能删，`/d2 定时 现在 2` 可以立刻试跑一次。
- **不想要了就说一句**：「dota2助手，取消所有定时任务」会把本会话的任务全部清掉，
  「把 2 号删掉」「定时 删 2」删单个，「停 2 / 开 2」临时停用不丢任务。
- **想改时间也说人话**：「把这个定时任务的执行时间改到早上八点」。只给钟点时沿用原来的
  周期（每周五 23:00 → 每周五 08:00），不会偷偷变成每天都发。
- **到点发的不是 AstrBot 的默认模型，而是这个插件自己**——数据源降级、中文英雄名、
  英雄池版本口径、你配的专用模型通道，全都和手动查询一模一样。
- **按场次的任务**（「每监听到 N 场」）不走定时器：它数的是**推送成功**的比赛，
  攒够 N 场就发一份这段时间的小结，然后重新开始数。插件重启也不会把攒的场次弄丢。
- 只有跟 Dota2 数据有关、且带时间或场次的说法才会被接住。
  「每天七点提醒我喝水」这类纯提醒请用手机闹钟——插件做不了，也不会假装能做。
- 定时任务可以在插件配置里整体关掉（`schedule_enabled`）；时区跟随 AstrBot 的全局设置，
  服务器在别的时区时记得填 `schedule_timezone`。

## 常见问题

**查不到我的比赛？**
先确认 Dota 2 里开了「公开比赛数据（Expose Public Match Data）」，关着的话任何工具都查不到。

**群里收不到播报？**
九成是没开上面那条「机器人主动在群聊内发言」权限（每个群都要单独开）。日志里会写明是不是这个原因。

**报告被截断了？**
调大 `llm_max_tokens`（0 表示不限制），或把 `analysis_as_image` 关掉改用文本发送。

**要填 API Key 吗？**
不用。OpenDota 匿名额度对个人/群聊使用足够（约 60 次/分钟、2000 次/天）。填 `opendota_api_key` 能提到 1200 次/分钟，适合人多或频繁查询。

**为什么有的复盘少了逐分钟经济、团战、出装？**
这些来自录像解析，只有**已解析**的比赛才有。插件会自动催解析并等待，最多 10 分钟；等待期间会播报进度（嫌吵可关 `parse_notify_progress`）。

**服务器在国内，接口时好时坏？**
填 `http_proxy`。主源抖动时会自动切后备；如果你更想要单一稳定的源，可以把 `data_source_priority` 改成 `opendota`（只用 OpenDota，不依赖 STRATZ 令牌与出口 IP）。

**想让报告用更便宜的模型？**
填 `llm_api_key` + `llm_base_url`（可以直接填服务商名，如 `deepseek`、`kimi`、`qwen`、`zhipu`、`siliconflow`、`openrouter`、`ollama`，会自动补全地址）+ `llm_model`，然后发 `/d2 模型测试` 自检。这条通道**只管报告与分析**。

**闲聊和报告用的是同一个模型吗？**
不是。群里的闲聊、说人话查战绩（含模型自己调工具）走 **AstrBot 全局配置的默认模型**；只有 `/d2 分析`、`/d2 单场`、监听短评、定时播报这类**长文分析**才优先走插件专用 Key。这样既能用便宜的全局模型接住高频唠嗑，又不会让专用 Key 的额度被闲聊吃掉。默认模型拿不到、或它调不动工具（不支持函数调用）时，闲聊会自动回退专用 Key，所以「一句话里要好几件事」不会因为默认模型不支持工具而答不全。

**报告太长刷屏？**
默认会把长报告转成图片发送（`analysis_as_image`），也可以调小 `max_message_length` 让它自动分多条。

## 数据说明

- 数据来自 [OpenDota](https://docs.opendota.com/) / [STRATZ](https://docs.stratz.com/) 公共接口，**不需要 Steam API Key**。
- 对局数据本身有延迟（通常落后官方几分钟到一小时），比赛播报天然存在时延。
- 逐分钟经济、团战、出装等来自**录像解析**，未解析的比赛只有基础统计。插件会自动催解析（每次催解析按 10 倍额度计费），但队列可能排队较久。
- 玩家必须在 Dota 2 设置里开启「公开比赛数据」，否则查不到比赛。
- 两个数据源的解析产物覆盖范围不同：最完整的复盘数据来自 OpenDota；走 STRATZ 时报告会基于它提供的字段来写（照样完整，只是进阶小节少一些）。
- 版本强势英雄榜来自 OpenDota 的 `/heroStats` **公开聚合接口**（不需要 Key、不消耗解析额度），统计窗口是**最近 7 天滚动的全分段样本**，因此它反映的是「最近这一周」而不是「当前补丁累计」——补丁刚发布时窗口里会混有上个版本的样本，插件会明确提示。它固定走 OpenDota，不受 `data_source_priority` 影响。
